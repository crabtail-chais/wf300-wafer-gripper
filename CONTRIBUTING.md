# Contributing

Please open an issue or pull request with a clear problem, the affected P1D1 file / drawing number, units, proposed change and evidence. Chinese or English is welcome.

- Distinguish calculations, assumptions, simulations, historical checks and measured results.
- Geometry changes should include native CAD, matching STEP / drawings / BOM, a revision note and comparison evidence. Do not silently overwrite a qualified or frozen baseline.
- Do not weaken safety checks to make a model pass. Report the unsupported condition and test it explicitly.
- Add manufacturing, ESD and particle-test records only when you have permission; remove customer identities, private wafer images and sensitive process details.
- Standard-part substitutions require exact orderable identity, source evidence and fit / force / contamination review. A vendor series is not an exact SKU.
- Contributions are made under the licence applicable to the changed files. Do not upload proprietary supplier CAD, standards text, secrets, private quotes or third-party code without compatible redistribution rights and notices.

Roadmap candidates: self-contained parametric generation; first-article build evidence; measured ergonomics; qualified ESD / contamination procedures; weight reduction with stiffness, ground-interface and manufacturability validation. These are proposals, not completed capabilities.
